What a run looks like

You type (Cowork form; in Claude Code prefix /piping-toolset:pressure-design):

design 750 psig at 600 F, corrosion allowance 0.0625 in, 12.5% mill tolerance. My allowable S at
600 F is 17900 psi from my copy, E = 1.0, W = 1.0, Y = 0.4. What minimum thickness do I need and

What it does

PipingToolset for Claude is a plugin: five skills, each a set of written instructions Claude follows plus a standard-library Python script that performs the calculation. Claude asks for the code basis and the inputs, writes a small specification file, runs the script by path, and reads the result back to you. The same engine behind the free calculators on this site produces the numbers.

How it works

1 · You describeThe line, the code and edition, the service, the inputs you have read from your licensed copy.
2 · Claude interviewsAnything missing is asked for. Anything you leave open is written down as ASSUMED.
3 · A script computesStandard-library Python, called by path, no network. Claude never does the arithmetic.
4 · You read the tableEdition, equation, inputs, result, verdict, warnings. Output files land in your working folder.

Three rules hold in every skill:

  • Claude never does the arithmetic. Every number a skill states comes from a script run on inputs you supplied. If you see a number and no script ran, treat the answer as untrusted and ask again.
  • Claude never recalls a code table value. Allowable stresses, moduli, SIFs, spans, ASCE 7 coefficients, anchor bond values: the skill names the table, row and edition and asks you to read it from your own copy. Asking for "just the number" is a pinned test, and the answer is no.
  • The edition is an input, never a silent default. Where a rule changed between editions (for example the f-factor form before and after B31.3-2022, or Appendix D giving way to B31J from B31.3-2020), the skill asks which one governs your project.

What it will not do

  • It will not give you a tabulated code value. Not an allowable stress, not a quality factor, not a Y coefficient, not an SIF, not a support span, not a catalog bond strength. You read those from the document you are licensed to use; the plugin contains none of them.
  • It will not replace a flexibility analysis. Stress screening is a hand check of what the program applied. CAESAR II and AutoPIPE remain the analysis tools; the load case builder and iso-to-PCF skills exist to feed them.
  • It will not pick your code or edition for you. Basis items you do not answer are marked ASSUMED on the calc sheet, never silently filled in.
  • It will not compute in the model's head. A skill that cannot run its script stops and says so instead of estimating.
  • It will not seal anything. Results are engineering aids. The engineer of record verifies them before issue, and you remain responsible for the result.
  • It will not reproduce code text. Paragraph numbers and equation references are cited; the wording of the standard is not included.
  • It will not touch your Piping Toolset account. The plugin is free and separate from the site's paid tiers. Installing it unlocks nothing on the site, and a subscription changes nothing in the plugin.

Where your data goes

Short answer: nothing you enter reaches PipingToolset or Flexible Piping Solutions. The plugin makes no network calls, carries no telemetry, needs no API key and no account with us. The only contact with our infrastructure is the download, and that is served by GitHub.

Install

In Claude Cowork

  1. Download piping-toolset.plugin from the latest GitHub Release.
  2. Drag the file into a Cowork chat. A preview card appears; press Accept.
  3. Start a fresh chat. The five skills appear in the skills menu under PipingToolset.

Or, in the app's plugin settings, add the marketplace pipingtoolset/pipingtoolset-claude.

In Claude Code

/plugin marketplace add pipingtoolset/pipingtoolset-claude
/plugin install piping-toolset@pipingtoolset

Then call a skill by its slash name: /piping-toolset:pressure-design, /piping-toolset:stress-screening, /piping-toolset:load-case-builder, /piping-toolset:pipe-support, /piping-toolset:iso-to-pcf. In Cowork there is no slash prefix; name the skill in plain words ("use the pipe support skill to check PS-201"). Naming it matters, because other installed skills on the same topics would otherwise compete.

Requirements

Python 3.9 or newer wherever the skills run: your own machine for Claude Code; Cowork's sandbox provides it. There is nothing else to install.

Try it in twenty seconds

Paste the worked example at the top of this page. Then ask for what it will not give you:

Use the pressure design skill. What's the allowable stress for A106 Grade B at 650 F under B31.3?
Just give me the number.

Expected: no number. It names B31.3 Table A-1 (A-1C in the 2024 edition), the material row and the two temperature columns, and offers to interpolate once you have read both values. Ten more prompts with pass criteria are in the repository's test prompt set.

How it is verified

  • One engine. Every script that computes a code equation reproduces the locked fixture cases of this site's calculation engine, value for value. A red parity test blocks a release. The fixtures and the method are described on the validation page and listed on the coverage page.
  • Golden outputs. The load case generator's tables and the PCF builder's output are locked byte for byte for the worked examples. A change to case order, combination strings or QC text is a deliberate, reviewed golden update.
  • Content guard. An automated test fails the build if any skill text or script embeds a tabulated code value or third-party proprietary material.
  • Recall channel. An installed copy keeps any defect it shipped with until you update it. A release labelled UNCONSERVATIVE-FIX in the changelog and on GitHub Releases corrects a result that could have been less conservative than the code requires, and names the skill, the affected inputs and the fix. Update when you see one.

Questions

Do I still need my own copy of the code?

Yes. The skills cite paragraphs and equations and ask you to read table values from your licensed copy. They are a way to apply the code correctly and traceably, not a substitute for having it.

Which codes and editions?

ASME B31.3 and B31.1 for pressure design, screening and load cases, with the edition as an explicit input wherever a rule differs between editions. Pipe support checks use ASCE 7-22, AISC 360-22, ACI 318-19 Chapter 17 and AWS D1.1. The iso-to-PCF skill targets the CAESAR II PCF import.

Does it work in the claude.ai chat, or in other assistants?

It is built and tested for Claude Code and Claude Cowork, which can run the bundled scripts. Running the same skills in other AI assistants is under evaluation; the skill format is an open standard and the scripts are plain Python, so watch the repository for news.

How much does it cost?

Nothing. The plugin is free and open source under the Apache License 2.0. You pay only for your own Anthropic plan.

How do I report a wrong result?

Open an issue in the GitHub repository with the prompt, the script command that ran and the line you dispute, or write to support@pipingtoolset.com. A confirmed unconservative result ships as an UNCONSERVATIVE-FIX release.
