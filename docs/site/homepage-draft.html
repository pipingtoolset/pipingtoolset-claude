Piping Toolset is a browser-based suite of piping, pressure-equipment, and support-structure calculators built for engineers who need report-grade output they can hand to a reviewer. Every calculator is a pure function: the same inputs always return the same result, and each one is locked behind a fixture-verified worked example that must reproduce a hand-checked reference case before a release ships.

Every free calculator runs entirely in your browser: its inputs are never transmitted to a server, so line numbers, design conditions, and process data stay on your device. The few paid features that need a server, such as PiperFEA solves and cloud-saved designs, send only the model you submit and say so where you use them. Piping Toolset is operated by Flexible Piping Solutions LLC.

Open a toolset below, run a calculation, and add the result to a project report with a titleblock, a captured-calculation list, and print-to-PDF output. The calculators' fixture-verified scripts now run inside Claude Code and Claude Cowork as a free plugin; see PipingToolset for Claude below.
