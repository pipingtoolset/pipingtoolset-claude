# Code basis, embedded values and known engine behaviour

## Editions

| Code | Edition | Used for |
|---|---|---|
| ASCE/SEI 7 | 2022 | Load combinations 2.3.1, 2.3.4, 2.3.6, 2.4.1, 2.4.4, 2.4.5; Ev = 0.2 SDS D (12.4.2.2) |
| AISC 360 | 2022 | Members (B4, D, E, F, G, H), welds (J2), bolts (J3), affected elements (J4), bearing (J8) |
| AISC Design Guide 1 | 3rd ed. method | Base plate bearing and yielding |
| ACI 318 | 2019 | Anchoring to concrete (Ch. 17), bearing (14.5.6), pier |
| AWS D1.1 | governing edition, user-confirmed | Prequalified joints, WPS, matching filler, inspection: **cited by topic only** |

## What is embedded, and what the user supplies

- **Embedded:**
  - AISC 360-22 equations, resistance and safety factors.
  - Table J2.4 / J2.3 size limits, Table J2.5 weld strengths, Table J3.2 bolt stresses, Table J3.3 standard holes and Table J3.4 edge distances. The AISC Specification is published free by AISC.
  - The ASCE 7-22 combination factors, verified against the Standard's text.
  - ACI 318-19 Ch. 17 equations, φ factors and generic cast-in values. The engine flags these generic values when they are used.
- **AISC shapes:** the AISC Shapes Database v16 (free from AISC) for rolled shapes. L, HSS and Pipe are computed from nominal geometry (HSS/Pipe design wall 0.93 t_nom). See the attribution in `data/aisc_shapes.json`. Confirm final selections against the Manual.
- **Always supplied by the user:**
  - Post-installed anchor product values (bond stress τ, kc, edge and spacing limits) from the ESR.
  - Soil properties (bearing, friction, cohesion) from the geotech report.
  - SDS.
  - Slip-critical pretension Tb (Table J3.1) and slip class.
- **Not reproduced:** AWS D1.1 tables and figures.

## Verification

- Every engine module reproduces the pipingtoolset.com PiperSTR engine:
  - the locked web fixtures, plus several hundred goldens generated by running the web engine itself;
  - `tests/test_pipe_support_ps101.py` reproduces a published PiperSTR Design Summary Report value for value. That covers all 28 limit-state rows (demand, capacity, ratio, clause), the 7 stage ratios and components, 6 base reactions, 2 lateral loads, the verdict and the 11 assumption lines.
- New modules (loads, bolts, detailing, optimizer, review) are covered by their own tests:
  - bolt values against AISC Manual tabulated strengths;
  - combinations against the ASCE 7-22 text.

## Known engine behaviour - reported, reproduced for parity, cross-checked where it matters

These were found while porting. The skill reproduces the web engine exactly, so results
match pipingtoolset.com. The reviewer adds a finding wherever one of these could change a
verdict.

1. **Column-to-base-plate weld: the base part is the plate.** The engine passes the base plate
   thickness as the "base part". The Table J2.4 minimum and the J4-4 base-metal rupture are then
   computed on the plate, not the thinner column element. The minimum-size warning is
   therefore over-conservative, and the base-metal capacity can be **unconservative**.
   The skill adds a `Base metal, column side [cross-check]` row (J4-4 on min(tf, tw)) to that
   weld stage. It counts in the verdict, the envelope, the optimizer and the compliance matrix,
   and `review.py` explains it as a **major** finding. Engine stage rows are never altered.
2. **Base plate: "Concrete breakout (tension)" compares the total group tension** with the group
   capacity Ncbg. This is consistent; the steel, pullout and bond rows are per anchor.
3. **Base plate: the post-installed splitting factor ψcp,N** evaluates to 1.0 in every case (an
   inner `max` where `min` looks intended), so splitting never reduces capacity. Review
   anchors near edges against the ESR's own critical edge distance.
4. **Base plate: the 17.6.2.1.2 reduced hef** uses the pier edge distances, not ca1.
5. **Fillet weld: L/w < 4** warns but does not reduce anything. J2.2b limits the effective
   *size* to 1/4 of the length; the engine's warning text speaks of the effective length.
6. **WT flexure, F9 LTB term B** is always taken positive. With the stem in compression this is
   unconservative. Avoid WT arms with the stem down, or check them by hand.
7. **Cantilever with no columnHeight** returns NaN for the base moment. The skill's spec
   validation requires it.
8. **Goalpost / trapeze headers** are not checked as spanning members. Check the header
   separately.
9. **Pier with a resultant outside the footing** returns an infinite soil ratio. That means
   "footing too small", not a numerical fault.

10. **ASD anchorage** converts the ACI 318-19 (strength-design) anchor capacity to an allowable
    value with a fixed 1/1.5 (R17.5.3). For a wind-governed ASD combination (0.6W) the
    implied factor is 1/0.6 = 1.67, so ASD anchorage can be about 10 % unconservative there.
    Run anchorage in **LRFD**, or check wind-governed anchors by hand.

## Not generated - supply by hand when they apply

- **Seismic overstrength combinations** (Em with Ω0, ASCE 7-22 2.3.6 / 2.4.5 second sets),
  needed for some anchorage designs. Map a case scaled by Ω0 as `Eh` and re-run.
- **Torsion** (H3) of the column under longitudinal pipe loads: reported, not checked.

Report items 1, 6 and 10 to the user whenever the design is close to a limit in that element.
